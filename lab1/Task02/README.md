# Отчёт по лабораторной работе 1

## Task02
Хромой король.На квадратной доске расставлены монеты, достоинством от 1 до 100. 
Хромой король, находящийся в правом нижнем углу, мечтает попасть в левый верхний.
При этом он может передвигаться только в клетку слева или сверху и хочет, чтобы сумма всех
монет, оказавшихся у него на пути, была бы максимальной.Определить эту сумму и путь, каким
образом должен двигаться король, чтобы ее собрать.Ввод и вывод организовать при помощи
текстовых файлов.Формат входных данных : в первой строке входного файла записано число 
N - размер доски(1 < N < 80).Далее следует N строк, каждая из которых содержит N целых чисел,
представляющих доску.В первую строку выходного файл нужно вывести единственное число :
максимальную сумму, а во второй строке вывести путь в виде строки символов, обозначив сим
волом L движение влево, а символом U - движение вверх.

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task02.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробеоа

### 2. Заголовки
- **Где:** Task02.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
- **Решение:** Добавлены недостающие заголовки

### 3. Использование пространств имён
- **Где:** Task02.cpp
- **Проблема:** В файле используется пространство имён std;
- **Решение:** Убрана строка "using namespace std;". Где необходимо, добавлено
              "std::", например, для "cin" и "cout"

### 4. Глобальная переменная
- **Где:** Task02.cpp
- **Проблема:** В файле используется глобальная переменная "n"
- **Решение:** Переменная больше не объявлена глобально. Она объясвлена там,
              где это необходимо

### 5. Отсутствие проверок
- **Где:** Task02.cpp, p(), main()
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к зависанию в бесконечных цикалх или к ошибкам
               в расчётах
- **Решение:** Добавлены дополнительные проверки

### 6. Вывод ответа с пробелами
- **Где:** Task02.cpp, p()
- **Проблема:** В функции к строке прибавлялось "L " или "U "
- **Решение:** Исправлено сложение строк. Теперь прибавляется "L" или "U"


### 7. Именование не по стилю
- **Где:** Task02.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
