# Отчёт по лабораторной работе 1

## Task04
Во всех заданиях данной подгруппы предполагается, что исходные строки, определяющие выражения, 
не содержат пробелов.При выполнении заданий не следует использовать оператор цикла.
Вывести значение логического выражения, заданного в виде строки S.Выражение определяется следующим 
образом(«T» — True, «F» — False) :
    <выражение> :: = T | F | And(<параметры>) | Or(<параметры>)
    <параметры> :: = <выражение> | <выражение>, <параметры>

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task04.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task04.cpp
- **Проблема:** В файле есть лишние заголовки, которые не используются
- **Решение:** Удалены недостающие заголовки

### 3. Скобки
- **Где:** Task04.cpp, evaluate()
- **Проблема:** Функция не учитывала кобки, из-за чего программа неправильно
               считывала выражение
               "Or(T,F),T" считывалось как "Or(T","F)" и "T"
- **Решение:** В функцию добавлен параметр глубины. Теперь если программа считывает
              скобку, то она идёт не до ближайшей следующей скобки, а ищет запятую,
              которая находится после закрывающей скобки
              "Or(T,F),T" считывается как "Or(T,F)" и "T"

### 4. Логика And и Or
- **Где:** Task04.cpp, evaluateAnd(), evaluateOr()
- **Проблема:** Блок вычислений считал значение выражения полностью
- **Решение:** Теперь evaluateAnd() и evaluateOr() имеют условие раннего выхода
              Если evaluateAnd() встречает 0, то результат 0
              Если evaluateOr() встречает 1, то результат 1

### 5. Лишняя функция
- **Где:** Task04.cpp, Recur23()
- **Проблема:** Функция содержит код, который можно оставить в main()
- **Решение:** Удалена функция Recur23(), код перенесён в main()

### 6. Именование не по стилю
- **Где:** Task04.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
