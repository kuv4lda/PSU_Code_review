# Отчёт по лабораторной работе 1

## Task01
Археолог нашел N артефактов.Известны веса(сi) и ценности(di) артефактов.Нужно
выбрать такое подмножество найденных вещей, чтобы суммарный их вес не превысил Z кг, а их
общая ценность оказалась максимальной.Известно, что решение единственно.Укажите поряд
ковые номера вещей, которые нужно взять.Исходный данные находятся в текстовом файле, в
первой строке указаны N и Z, а во второй строке значения весов(в кг), в третьей - ценность
находок.Вывести так же суммарный вес и общую ценность результата.

## Список исправленных ошибок

### 1. Отступы
- **Где:** Task01.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Заменены отступы табуляцией (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task01.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
- **Решение:** Добавлены недостающие заголовки

### 3. Использование пространств имён
- **Где:** Task01.cpp
- **Проблема:** В файле используется пространство имён std;
- **Решение:** Убрана строка "using namespace std;". Где необходимо, добавлено
              "std::", например, для "cin" и "cout"

### 4. Глобальная переменная
- **Где:** Task01.cpp
- **Проблема:** В файле используется глобальная переменная "n"
- **Решение:** Переменная больше не объявлена глобально. Она объясвлена там,
              где это необходимо

### 5. Отсутствие проверок
- **Где:** Task01.cpp
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к зависанию в бесконечных цикалх или к ошибкам
               в расчётах
- **Решение:** Добавлены дополнительные проверки

### 6. Именование не по стилю
- **Где:** Task01.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
