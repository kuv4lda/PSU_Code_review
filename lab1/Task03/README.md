# Отчёт по лабораторной работе 1

## Task03
К-ичные числа. Среди чисел в системе счисления с основанием K (2≤K≤10) определить сколько 
имеется чисел из N (1<N<20, K+N<26) разрядов таких, что в их записи не содержится два и 
более подряд идущих нулей. Для того, чтобы избежать переполнения, ответ
представьте в виде вещественного числа.

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task03.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task03.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
               В файле есть лишние заголовки, которые не используются
- **Решение:** Добавлены недостающие заголовки. Удалены лишние заголовки

### 3. Неправильный счёт
- **Где:** Task03.cpp
- **Проблема:** В функции считались все числа без "00", включая числа,
               начинающиеся с "0", ответ получался завышенным
- **Решение:** Теперь первая цифра задаётся отдельно как ненулевая (K-1),
              а оставшиеся N-1 считаются как допустимый хвост без "00"

### 4. Счёт в основном блоке
- **Где:** Task03.cpp, main()
- **Проблема:** Вычисления производились в основном блоке программы
- **Решение:** Вычисления вынесены из главного блока программы и теперь
              производятся в добавленной функции CountNumbers()

### 5. Отсутствие проверок
- **Где:** Task03.cpp
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к ошибкам в расчётах
- **Решение:** Добавлены дополнительные проверки

### 6. Именование не по стилю
- **Где:** Task03.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
