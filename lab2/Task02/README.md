# Отчёт по лабораторной работе 2

## Task02
Даны указатели P1 и P2 на начало и конец непустой очереди. Извлекать из очереди
элементы, пока значение начального элемента очереди не станет четным, и выводить значения
извлеченных элементов(если очередь не содержит элементов с четными значениями, то извлечь
все ее элементы).Вывести также новые адреса начала и конца очереди(для пустой очереди
дважды вывести nullptr).После извлечения элементов из очереди освобождать память, которую
они занимали.


Для каждой динамической структуры должен быть предусмотрен стандартный набор методов -
добавления/удаления/вывода элементов.
Во всех задачах обязательно наличие дружественного интерфейса. Ввод данных с клавиатуры.



В заданиях данной подгруппы структура «очередь» (queue) моделируется цепочкой связанных
узлов-записей типа TNode. Поле Next последнего элемента цепочки равно nullptr. Началом
очереди («головой», head) считается первый элемент цепочки, концом («хвостом», tail) — ее
последний элемент. Для возможности быстрого добавления в конец очереди нового элемента
удобно хранить, помимо указателя на начало очереди, также и указатель на ее конец. В случае
пустой очереди указатели на ее начало и конец полагаются равными nullptr. Как и для стека,
значением элемента очереди считается значение его поля Data.

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task02.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task02.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
- **Решение:** Добавлены недостающие заголовки

### 3. Использование пространств имён
- **Где:** Task02.cpp
- **Проблема:** В файле используется пространство имён std;
- **Решение:** Убрана строка "using namespace std;". Где необходимо, добавлено
              "std::", например, для "cin" и "cout"

### 4. Узел Node
- **Где:** Task02.cpp
- **Проблема:** Узел Node был приватным вложенным, код не мог его использовать
- **Решение:** Узел TNode вынесен наружу в отдельную структуру

### 5. isdigit требует int
- **Где:** Task02.cpp, IsNumber()
- **Проблема:** IsNumber() использовал isdigit(str[i])
- **Решение:** isdigit(str[i]) заменён на isdigit(static_cast<unsigned char>
               
### 6. getP1() и getP2() возвращали указатель на приватный тип
- **Где:** Task02.cpp, getP1(), getP2()
- **Проблема:** внешний код не мог использовать Node*
- **Решение:** TNode вынесен наружу, публичные getP1() и getP2() удалены

### 7. Отсутствие проверок
- **Где:** Task02.cpp
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к зависанию в бесконечных цикалх или к ошибкам
               в расчётах
- **Решение:** Добавлены дополнительные проверки

### 8. Именование не по стилю
- **Где:** Task02.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
