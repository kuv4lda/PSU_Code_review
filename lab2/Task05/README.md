# Отчёт по лабораторной работе 2

## Task05
Элементами контейнеров являются целые числа. Для
заполнения контейнера использовать итератор и конструктор соответствующего контейнера,
для вывода элементов использовать итератор (для вывода элементов в обратном порядке
использовать обратные итераторы, возвращаемые функциями-членами rbegin и rend)
Обязательно наличие дружественного интерфейса. Ввод данных организовать
разными способами (с клавиатуры, рандом, из файла)


 Дан дек D с нечетным количеством элементов N (≥ 5). Добавить в начало дека пять
его средних элементов в исходном порядке. Использовать один вызов функции-члена insert.

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task05.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task05.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
               Есть лишние заголовки
- **Решение:** Добавлены недостающие заголовки, лишние удалены

### 3. Использование пространств имён
- **Где:** Task05.cpp
- **Проблема:** В файле используется пространство имён std;
- **Решение:** Убрана строка "using namespace std;". Где необходимо, добавлено
              "std::", например, для "cin" и "cout"

### 4. IntDeque
- **Где:** Task05.cpp, IntDeque{}
- **Проблема:** Отсутствовал класс
- **Решение:** Добавлен класс, конструктор, метод добавления в конец, методы
              вывода через итератор и обратный итератор

### 5. Файл
- **Где:** Task05.cpp
- **Проблема:** Имя файла заблокировано
- **Решение:** Добавлен запрос названия файла

### 6. Вывод
- **Где:** Task05.cpp
- **Проблема:** Выводы были не через итераторы
- **Решение:** Реализованы выводы через итераторы

### 7. Отсутствие проверок
- **Где:** Task05.cpp
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к зависанию в бесконечных цикалх или к ошибкам
               в расчётах
- **Решение:** Добавлены дополнительные проверки

### 8. Именование не по стилю
- **Где:** Task05.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
