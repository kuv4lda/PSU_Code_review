# Отчёт по лабораторной работе 2

## Task03
Все динамические структуры данных реализовывать через классы. Не использовать STL.  Для каждой динамической структуры должен быть предусмотрен
стандартный набор методов - добавления/удаления/вывода элементов. Во всех задачах обязательно
наличие дружественного интерфейса. Ввод данных с клавиатуры.


Дан текстовый файл, в первой строке которого хранится число N, а во второй
строке N целых чисел. Необходимо создать упорядоченный по убыванию список, в который
поместить все эти элементы, при этом очередной элемент вставлять в список так, чтобы не
нарушалась его упорядоченность.

## Список исправленных ошибок

### 1. Табуляция
- **Где:** Task03.cpp
- **Проблема:** Отступы не по стилю
- **Решение:** Замена табуляции (4 пробела) на 2 пробела

### 2. Заголовки
- **Где:** Task03.cpp
- **Проблема:** В файле отсутствуют необходимые заголовки, которые используются
- **Решение:** Добавлены недостающие заголовки

### 3. Использование пространств имён
- **Где:** Task03.cpp
- **Проблема:** В файле используется пространство имён std;
- **Решение:** Убрана строка "using namespace std;". Где необходимо, добавлено
              "std::", например, для "cin" и "cout"

### 4. LinkedList
- **Где:** Task03.cpp, LinkedList()
- **Проблема:** Отсутствовал деструктор, методы удаления, очистки и обработки
- **Решение:** Добавлен деструктор, методы удаления головы и по значению,
              метод полной очистки и обработки пустого списка

### 5. setlocale()
- **Где:** Task03.cpp, main()
- **Проблема:** Отсутствовала команда setlocale()
- **Решение:** Добавлена команда setlocale()

### 6. Отсутствие проверок
- **Где:** Task03.cpp
- **Проблема:** В коде отсутствовали проверки, некоторые значения могли
               приводить к зависанию в бесконечных цикалх или к ошибкам
               в расчётах
- **Решение:** Добавлены дополнительные проверки

### 7. Именование не по стилю
- **Где:** Task03.cpp
- **Проблема:** Некоторые функции или переменные имеют названия, которые
               не соответствуют стилю
- **Решение:** Функции и переменные переименованы в соответствии со стилем
